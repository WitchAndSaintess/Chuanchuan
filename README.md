# Chuanchuan
1818 She Niang - A Desktop Pet with a Local AI
Whether it's the future president, members, or just passing friends: Hello, I am the president of the 2025-2026 term of the 1818 Science Fiction Association. This is our club's "Club Girl" project file and source code. It's a very rough and simple work, freely open-sourced for everyone to use for entertainment development or learning. This project was developed entirely by hand. Due to messy variable names and irregular annotations, I used AI to refactor the code, and now the code is very clear :-D. If you downloaded Chuanchuan, simply double-click chuanchuan.exe to run it. The initial startup may be a bit slow, so be careful not to launch it too many times as it may freeze. To experience local AI, move the AI file (model.gguf) to the same directory as chuanchuan.exe, and you can start talking to ChuanChuan. If you don't want to experience it, you can simply double-click to run it and then right-click to enter the menu to import your own API key (you need to check the port yourself). 
 If you downloaded the Chuanchuan source code and want to develop and learn from it, the project code consists of two parts. One is the code files, with the main code files located in oc.py (python) and index.html (js, under the live2D folder). The other is the live2D file, which was created using Live2D Cubism Editor 5.0. Simply download the corresponding software and search for tutorials on Bilibili. Lastly, I hope you all have a happy day.
